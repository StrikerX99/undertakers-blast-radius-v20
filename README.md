# Undertakers Blast Radius V20.1

Build the source at the repository root with `docker build --platform linux/amd64 -t undertakers-v20 .`. The container accepts the organizer's test catalog and patch directory under `/data`. It emits a JSON worker plan for each commit.

The baseline dependency maps are observations of SQLGlot at `eb11aec4be8cb2122afe713a4816662c3f0fb2fa`. The selector applies the incoming diff to that source. It combines actual file and directory dependencies, import and dispatch observations, and coverage of costly methods including child processes. For narrow changes it evaluates semantic equivalence or reruns the affected assertions. It retains observed failures. The scheduler prices the longest worker load and each worker's setup time.

An executor query can change the SQL text printed for debugging while producing exactly the same result. V20 checks whether a changed string goes to the logger, Python compiler or DuckDB, and verifies it accordingly. A changed native result can establish a failure immediately when its row count disagrees with the pinned expected result for unchanged reference SQL. Native query work is recorded only while deciding the current patch, so later checks can reuse completed results. The build consumes no patch labels or other entrants' assets.

Only the contents of the submission ZIP belong in the public team repository. The separate evidence download includes benchmark inputs and answer keys for local use.

For a composite optimizer patch, the selector can use the first changed bytecode instructions to localize a single changed statement. It queries phased execution data from the pinned workload, then evaluates the remaining affected stages on the entire patched source. Unsupported edits use the existing dependency checks.

For a single added expression class, a separately budgeted verifier checks that old registry identities and ordering survive the patched import. It exercises all original TPC-DS inputs, optimizer graphs and execution boundaries before clearing that test.

For coordinated expression, parser and generator edits the selector combines each file's observed readers. It includes users of unchanged parser callbacks that lose an imported name, and checks imports against the full patch before narrowing the plan.
